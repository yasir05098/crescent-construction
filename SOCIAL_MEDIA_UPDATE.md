## 🎯 CUSTOMIZATION OPTIONS

### Change Icon Size:
Edit in `css/style.css`:
```css
.social-icon {
    width: 38px;    /* Change this */
    height: 38px;   /* And this */
}
```

### Change Colors:
Edit the background-color for each icon in `css/style.css`:
```css
.social-icon.facebook {
    background-color: #1877f2; /* Your color */
}
```

### Change Hover Effect:
Edit in `css/style.css`:
```css
.social-icon.facebook:hover {
    transform: translateY(-3px);  /* Change effect */
}
```
